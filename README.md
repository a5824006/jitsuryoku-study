# 実力試験ノート

2022～2025年度の過去問をもとに、基礎の復習と過去問演習ができる学習サイトです。
69テーマの基礎教材と199設問の解説を収録しています。

## 学習の進め方

- **基礎を思い出す**：要点と公式、例題を確認し、小テストと条件を変えた再テストで理解を確かめます。どこから復習するか迷う場合は、科目別の基礎診断を利用できます。
- **得点対策**：頻出テーマ、年度ごとの違い、答案で求められる条件を確認します。単問演習や年度別の練習セットでは、自分で時間を設定して取り組めます。
- **手順を可視化**：座標変換、CRC、ダイクストラ法の条件を変え、計算や操作を一段階ずつ確認できます。
- **自分の復習ノート**：「未着手」「復習が必要」「説明できる」の状態を記録し、お気に入りやメモを使って復習する問題を整理できます。

受験科目を設定すると、ホームに診断結果や復習状況に応じた次の学習が表示されます。
科目を選択せずに教材を読むこともできます。

## 過去問演習の使い方

科目、年度、テーマ、解答形式で問題を絞り込み、まず自分で解いてから答案例を確認します。
解説では、基礎知識、解法と途中式、答案例、間違えやすい点を確認できます。
文字数や指定語句などの要求条件は、問題ごとに表示されます。

自動確認に対応する問題は、回答を入力して結果を確認できます。
論述や図示は、答案例と確認項目を使って自己評価します。
「条件付き」の解説では、補った仮定を確認してください。

## 学習記録の保存

ログインは不要です。
記録は使用中のブラウザーに保存され、端末やブラウザーを変えても自動では同期されません。

「書き出し」でバックアップを保存し、移動先の「読み込み」で復元できます。
ブラウザーのデータを削除する前にも、バックアップを保存してください。

## 出題傾向を確認する

[過去問の傾向分析](reports/analysis.md)と[科目別の全設問分析](reports/subjects/)を参照できます。
出題頻度は、そのテーマが出題された年度数を、収録年度数で割った値です。
今年の出題や採点基準を保証するものではありません。
教材の答案例は公式解答ではなく、試験時間や配点は確認できた年度の条件として掲載しています。
